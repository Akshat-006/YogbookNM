## Coding Standards

### Feature-Based Architecture
Each feature must keep:
- components/
- hooks/
- services/
- types/

Optional:
- schemas/

### Business Logic Rules
- Business logic stays inside services.
- Hooks only call services.
- Components do not call APIs directly.

### Frontend Rules
- Keep components reusable.
- Separate dialogs.
- Keep tables independent.
- Use React Query everywhere.
- Use React Hook Form + Zod for forms.
- Do not use plain HTML validation.

### Backend Rules
- Service layer, router, schema, utils, and database must stay separated.
- Do not place business logic inside routers.

### Payments Flow
Booking -> Payment -> Verify -> Email -> Dashboard

Payment must be completed before confirmation.

### Emails
All emails are backend-driven: 
- OTP
- Booking confirmation
- Appointment confirmation
- Payment success
- Login OTP
- Contact reply
